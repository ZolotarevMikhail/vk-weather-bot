# VK-бот погоды

Бот для сообщества ВКонтакте: погода по названию города, прогноз на 5 дней,
сравнение двух городов, расширенный режим (давление, видимость, качество
воздуха) и погода по геолокации. Учебный проект урока VPd04.

Python + vkbottle (LongPoll), данные — OpenWeather API.

## Функции

Бот отвечает кнопками в меню (в клиентах VK клавиатура открывается значком-сеточкой возле поля ввода) или обычным текстом.

- **Погода сейчас** — температура, ощущается как, ветер, влажность по названию города
- **Прогноз 5 дней** — сводка по дням из прогноза с шагом 3 часа
- **Сравнение городов** — два города через запятую, например «Москва, Сочи»
- **Расширенный режим** — давление, видимость, качество воздуха (шкала OpenWeather)
- **Геолокация** — точка на карте (скрепка → Геолокация) или координаты текстом: `55.7558, 37.6173`
- **Мой город** — бот помнит последний запрошенный город и повторяет его погоду
- **Помощь** — справка по командам

## Как запустить

1. Ключи нужны два: токен сообщества ВК (права «Управление» и «Сообщения»)
   и API-ключ OpenWeather. Оба кладутся в файл `.env` рядом с кодом
   (образец — `.env.example`), в код они не попадают.
2. Python 3.10+ и зависимости:

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Запуск:

```bash
python -m bot.main
```

Бот слушает сообщения сообщества через LongPoll — сервер держать запущенным.

## Структура

```
bot/            сам бот: main.py (точка входа), handlers.py (логика ответов),
                keyboards.py (кнопки), states.py (состояния диалога)
weather_api/    клиент OpenWeather: client.py, config.py, exceptions.py,
                utils.py (форматирование ответов)
cli.py          консольная версия: погода без бота, для проверки ключа
run_debug.py    отладочный запуск: добавляет логеру vkbottle недостающий
                метод .opt и печатает честный traceback при падении
```

Настройка состояния диалога — через `state_dispenser`: каждая кнопка меню
ставит ожидание ввода, следующий текст пользователя обрабатывается по состоянию.
Ошибки API (город не найден, ключ не задан) показываются сообщением, без падений.
